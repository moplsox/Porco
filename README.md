# 红猪：亚得里亚海的来信

非官方原创中文同人视觉小说。玩家扮演波鲁克，经历初夏到初秋的90天。菲尔在成年重逢后独立接单、签图；吉娜经营旅馆、决定自己的歌与生活。六章、两条个人线、八结局，邮航可以在感情错过之后继续。

## 直接打开游玩

仓库根目录的 **index.html 是完整单文件离线版**（约63 MiB）。下载保存后，直接用桌面 Safari、Chrome、Edge 或 Firefox 打开即可；不需要Node.js、Python、本地服务器、网络或旁边的资源文件。GitHub文件页面请使用 **Download raw file** 保存文件，再双击，不要在GitHub代码预览页里运行。

剧本、界面、立绘、背景、CG及原创合成音频均已内嵌。内嵌图片采用无损WebP编码，原始PNG仍在assets目录保留。

手机请使用支持本地HTML执行的浏览器/打开方式；系统的文件预览器不一定执行JavaScript。移动端也可使用已部署的网页版。浏览器允许本地存储时可正常存档；若禁止持久保存，游戏会保留本次会话内的临时槽位并提示导出。

## 修改源码与构建

日常修改仍使用src/、data/与assets/中的独立文件。**不要手工改生成的根目录index.html。**

重新生成离线文件需要Node.js、Python3及Pillow（包含WebP编码支持）：

```bash
python3 -m pip install Pillow
npm run build
```

`npm run build` 会更新根目录单文件index.html，并生成供静态网站托管的dist/。首次构建会创建被Git忽略的.cache/standalone-art无损图像缓存，之后按哈希复用。只重新生成单文件可用`npm run build:standalone`。

已有网页版存档可通过“导出当前存档”保存为JSON，再在离线版导入。浏览器会按文件地址管理本地存储，移动或改名之前建议先导出。

## 本轮美术与游泳约会

按用户审阅稿接入11个地点的33个昼夜雨天背景视区、12套透明立绘图集（72个表情，含吉娜工作装别名共78槽位）。草帽菲尔、第一版湿发白上衣与白色中腿短裤、波鲁克额头护目镜加墨镜均已实际接入。运行画面不会显示审阅表格、标签或相邻人物。

六张CG原样保留：yellow-quilt、dinner-fio、last-boat、storm、kitchen、key。其余六张重绘为独立横向CG，新增游泳一张，共13张。保留文件按SHA256校验，记录见 docs/ART-PRESERVED.json。

第40天上午菲尔会主动邀请波鲁克去海湾休假：可接受两天后的下午、改到四天后或婉拒。约会免费，不耗油；晴天可戏水、安静漂浮或留在岸边，雨天去棚下分桃子。菲尔线可明确提出恋爱邀约，其他路线保持友情；五天后按实际赴约日回收记忆。新增11场、约5300字正文，已有存档可继续游玩。细节见 docs/SWIMMING-STORY.md。

生成PNG原件保留；离线及托管封装采用像素无损WebP，保留alpha和所有可见像素。美术数量与制作方式见 docs/ART.md，验证见 docs/REFERENCE-ART-QA.md。

## 操作

点击对白、空格或Enter推进；1–4选项；H历史；S快捷存档；L快捷读档；Esc关闭面板。手机直接触控。旋转屏幕不会重建游戏状态。

从标题选择“开始这个夏天”。读完当期主线后进入海图，到机库/旅馆查看事件与邀请，去市场公告板接委托。地图六地点聚合其附近场景：旅馆含厨房和花园，集市含渡轮，海湾/灯塔含海上。专属事件在相应章、时段可访问；地图会显示当期可知安排。

日历可提前邀请、赴约、捎信改约，机库可免费修泵恢复收入与油料。跳过平淡日子会停在下一主线或约定。第31天明确选择空闲先留给谁，夏末再次亲口决定。亲密与信任分别记录，默认隐藏数值。好结局需要关键行动与最后的明确选择。

## 存档

自动存档、快捷存档、9个手动槽、6章检查点全部在浏览器 localStorage。包含场景、条件过滤后的正文、对白位置、选项回复、日期时段、钱油机况、关系、约定、全部旗标与账本。支持JSON导出/导入，清理浏览器前请导出。相册和已读进度另存为全局回忆。

## 内容与资源

- `data/`：实际接入的六个剧情文件、24项委托和审计结果。
- `src/engine.js`：条件、效果、日历、经济、约定、路线与结局规则。
- `src/app.js`：标题、对话、地图、全功能面板和存读档界面。
- `src/audio.js`：原创Web Audio海浪、风、远处发动机与钢琴，无外部录音。
- `assets/`：审阅背景、透明立绘图集、资源视区清单、13张事件CG。
- `docs/`：内容契约、每线选择—标记—回收表、美术状态、验收记录。
