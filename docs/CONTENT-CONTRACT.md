# Content contract
All content files are JSON arrays of Scene objects. Writers own separate files.
Scene: {id,title,chapter:1..6,day:1..90,period:0|1|2,location:'cove'|'hangar'|'hotel'|'market'|'post'|'lighthouse'|'sea'|'kitchen'|'garden'|'ferry',kind:'main'|'event'|'date'|'quest'|'ending',route?:'fio'|'gina'|'friend'|'solo',order?:number,lines:[Line],choices?:[Choice],effects?:Effect,cg?:string,next?:string,ending?:string,requires?:Condition}
Line: {speaker:'波鲁克'|'菲尔'|'吉娜'|other|'旁白',text:string,when?:Condition,expression?:'neutral'|'smile'|'serious'|'sad'|'surprise'|'tired',outfit?:'work'|'date'|'stage'|'morning'}.
Choice: {text,reply?:string,next?:string,effects?:Effect,when?:Condition}. next is for immediately chained branch scenes only. Without next returns to daily map after applying effects; elapsed time managed by engine. Branch scenes can use day:0 and kind:event, never auto-scheduled.
Effect: {money?:number,fuel?:number,condition?:number,mail?:number,fioClose?:number,fioTrust?:number,ginaClose?:number,ginaTrust?:number,flags?:{[key]:boolean|string|number},promise?:{id:string,person:'fio'|'gina',day:number,period:number,title:string},resolvePromise?:string}
Condition: {flag?:string,eq?:boolean|string|number,notFlag?:string,route?:'fio'|'gina'|'friend'|'solo',fioTrust?:number,ginaTrust?:number,fioClose?:number,ginaClose?:number} all fields AND. flag without eq checks truthiness; notFlag checks falsy. No code inside content. Conditional lines all count only if condition is satisfiable.
Use globally unique IDs. Background inferred from location; CG identifiers provided below. Character portraits inferred from last speaker.
A game day = June 1 + day-1, day 1 Monday, day 3 Wednesday, day 4 Thursday. chapter boundaries day 1,16,31,46,61,76. Main scenes due on scheduled day/period force play; optional event/date becomes available from day until chapter end at its location; no auto-expiry penalty. Choose route at day 31. Both characters still work regardless route. Engine runs main scenes route independent. Dates are invited explicitly, cost/time metadata extra: cost, duration (1 or 2), invitation (short text). Event minimum 12 per heroine + six distinct dates each. Route filter only after explicit route decision, optional scenes before it are visible.
CG ids: letter, yellow-quilt, dinner-fio, kitchen, silence, dock, mailbag, storm, first-flight, key, garden, last-boat. Add cg to actual matching scene only.
Endings engine chooses day90 based explicit intent and trust/action flags: fio_good (route fio, fioTrust>=8, flag fioCareer), fio_open (route fio, fioTrust>=3), fio_missed otherwise; gina_good (route gina, ginaTrust>=8, flag ginaKey), gina_open (route gina,ginaTrust>=3), gina_missed otherwise; friend (route friend), solo(route solo). Flags writers should use these exact names where appropriate.
Delayed mail chain common: flags letterChoice='return'|'search'|'message'; day3 selected, day4 feedback and day76 docks recall. Recipient named 马泰奥, carries yellow tin biscuit box. Tests will verify distinct outcomes.
Key memory flags suggested: pencil, honestLog, cushion, yellowQuilt, voiceGiven, blueTin, quietBoat, sideKey, keptThursday, dockRamp, senderName, stormWait. Every writer provide table under docs with choices, flags, delayed recall IDs.
All narration must be original Chinese prose/dialogue with concrete human life; no film quotes. Fio is 25, romance begins this reunion. Do not pad repeated lines. Count visible distinct text excluding choices/UI/code with scripts/audit.mjs. Aim your assigned word quota in actual visible lines. Every scene should have multiple conversational beats, actions, stakes, and choices.
