# 菲尔透明立绘修正 v19

版本：`native-seam-edge-v19`。保留用户选定的六套服装、每套六种表情，共36张完整透明PNG；旧 `fio-swim-*` 六槽继续别名到游泳后湿装。

本轮沿用现有姿势、衣服、头发和脸部外轮廓。面部只修复原表情局部覆盖的肤色接缝及旧笔画残留，表情细节来自既有认可图。边缘只清理纸底残留和已确认的发丝空隙，并保护深色轮廓、白衣、眼睛高光及湿装水滴；同一服装六种表情共用完全一致的透明度及身体。未生成新人物图。

游戏直接绘制每个表情的一张完成PNG，避免运行时叠加局部表情再次产生接缝。原图、视区和分层信息保留作来源记录；背景、CG、吉娜、波鲁克及剧情未因本轮接入而改变。

干泳装恢复为用户选定的白色上衣、蓝色短裤、手持格纹衬衫原图。游泳后仍使用湿发、白色短裤的独立湿装。

36张PNG的最终文件SHA256、透明通道SHA256、来源图SHA256及视区见 [FIO-NATIVE.json](FIO-NATIVE.json)。最终SHA为本版本的固定母版凭据，后续修图应另立版本，不覆盖本凭据。
