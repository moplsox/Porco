# 美术资产与替换记录

本项目全部游戏背景、人物和事件图均为新作构图，没有截取电影画面，没有使用原声录音。标题、人物模型表、10张独立背景以及12张事件CG使用本次会话的图像生成工具创作并落盘。SVG部分由代码直接原创绘制。背景与人物采用水彩纸纹、褪色招贴油墨和赛璐璐轮廓的统一方向。

## 人物统一设定

先绘制 `assets/character-setting.svg`，随后制作 `assets/character-setting-generated.png`，再制作CG与场景。

- 波鲁克：比两位女性矮，宽肩与粗壮体形；猪脸轮廓、白色胡须、棕色飞行帽和护目镜、米色飞行服及围巾。红色水上飞机属于其可识别的生活空间。
- 成年菲尔：25岁，独立工作的飞机设计师。短赤褐色蓬松发、成人身材和专注神情；青蓝背带工装、奶白衬衫、棕靴和铅笔。约会服为珊瑚橘色日裙，指甲油迹没有因换裙子消失。
- 吉娜：三人中最高，深褐色波浪短发、绿耳饰；外出服为灰绿色长裙，晨间为浅色舒适上衣与裙装，舞台服为蓝灰长裙。保留优雅轮廓，也保留疲惫和不想表演时的表情。

## 仍为原创临时插画的资源（准确范围）

1. **人物对话立绘**：菲尔 `work/date × neutral/smile/serious/sad/surprise/tired` 共12张；吉娜 `work/date/stage/morning × 6表情` 共24张。吉娜work与date是同一外出服命名槽，晨装与舞台装为独立造型。表情是实际不同的眼、眉、口型，服装和脸型由统一模板保持。全部为透明底SVG原创临时插画，尚未替换为与生成CG同精度的成套赛璐璐立绘。
2. **波鲁克对话形象**：`portrait-porco-work-*.svg` 六个命名槽共用一个寡言形象；本作始终由玩家扮演波鲁克，通常不在对话场景叠加其立绘。
3. **天气与夜景变体**：11个地点（含复用的dock）各自 `bg-{地点}-night.svg` 与 `bg-{地点}-rain.svg`，共22个文件；由完整的原创SVG场景构图配合月光、夜色、雨线与冷色绘制，未替换为生成背景同精度的水彩夜景或雨景。
4. **备用构图稿**：`bg-{地点}.svg`、`cg-{ID}.svg` 与 `cover.svg` 已由正式生成主图覆盖，属于保留原稿，不会当作额外相册项目。人物设定SVG同样保留作为源稿。

没有仍用临时图的事件CG，没有不存在或无法看到的相册项目。

## 文件与再生

- 运行入口使用 `assets/manifest.json`，不由UI猜测文件名。
- `assets/build-art.py` 重建原创SVG人物/场景；`assets/build-cg.py` 重建12张SVG构图稿。这两个工具会重置清单，应仅用于美术源稿再生。
- `python3 assets/finalize-art.py` 将已存在的生成PNG重新写入清单，并同步昼夜雨资源；交付前已经执行。
- 生成PNG原件保留在执行环境 `/workspace/generated_images`，游戏使用的副本均在项目 `assets/` 内，不依赖外部图片URL、电影素材或远程热链。
- 音景由游戏的Web Audio原创合成；音量与减少动态效果由设置面板管理。
