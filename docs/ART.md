地点包括海湾、海面、旅馆、机库、集市、邮局、灯塔、花园、渡轮、厨房和码头。昼夜雨天由游戏日期、时段与天气选择。旧背景源文件仍可追溯，但不在活动清单中，也不嵌入离线版。

## 制作、打包与验证

角色和新增CG用图像生成工具根据已审阅设定绘制，未截取电影画面充作本作新CG。参考PDF和本地参考路径不随游戏发布。背景复用已审阅画面分区，运行裁切由SVG呈现，不对原PNG做绘画处理。

源PNG保留。离线版和托管版采用像素无损WebP；编码校验alpha和所有可见RGBA像素相同。整张图集只解码一次，各表情/时段视窗复用同一资源。

`npm run test:art` 验证全部源文件、视区边界、透明、不同表情像素、保留图字节、替换图哈希及CG剧情引用。结果见 `REFERENCE-ART-QA.md`。画风与表演质量仍以实际图像审阅为准，哈希不证明外观与电影逐像素相同。

声音继续使用Web Audio原创环境音；没有恢复配音功能。
