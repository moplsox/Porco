# 菲尔邀约：游过海湾

新增正式剧情 11 个场景，入口在第40天上午；第42天下午赴约，或当面改到第44天下午。免费，游泳占1个下午，不要求燃油、现金或飞机状态。第40天之后继续的旧存档会补遇邀请，新游泳约定按实际邀约日后2天或4天下午计算，两种选择始终相差2天，与“后天”及“再后两天”的对白一致。无相对日期字段的旧约定仍沿用原来的过期顺延规则。第84天后不再补发邀请；已作夏末明确感情答复的存档也不补发。

玩家可以接受、当面改约或直接拒绝。接受后日历显示赴约入口；也可以使用现有捎信改约。实际赴约遇雨时只开放雨棚分桃子分支，不展示晴天游泳CG。晴天下水可选择互相泼水或安静漂一会儿，也允许波鲁克待在岸上。

浪漫表态仅在菲尔个人线显示，并要求玩家明确选择。吉娜线、友情线和独处线都保留友情回应，游戏不因游泳修改既定路线。亲密与信任分别反馈：菲尔可以喜欢今天的相处，同时仍把次日验证班交给按要求提交记录的同事；信任足够时，她邀请波鲁克优先提交载重记录，但休假不抵工作。

## 选择与回收

| 选择/行动 | 记忆标记 | 回收场景 |
|---|---|---|
| 接受第42天下午的主动邀约 | `fioSwimPlan=accept`、`fioSwimInvitationDay` | 日历 `fio_swim_plan`；准时赴约沿用守信效果 |
| 当面改到第44天下午 | `fioSwimPlan=rescheduled`、`fioSwimInvitationDay` | 日历显示新时间；不因明确改约惩罚信任 |
| 尊重自己的独处，直接拒绝 | `fioSwimPlan=declined` | 不建立约定；菲尔另约艾达，工作仍继续 |
| 晴天下水 | `fioSwimWeather=clear` | `fio_swim_water` 展示 `fio-swimming` CG；对白使用 `fio-swim-*` 立绘 |
| 留在岸上陪伴 | `fioSwimWeather=bankside`、`fioSwimFriend` | 菲尔自己游回；后续可邀请艾达一起去 |
| 改约后遇雨，改为雨棚休假 | `fioSwimWeather=rain` | 后续铁盒内的纸船和水痕；不解锁晴天游泳CG |
| 彼此允许后泼水 | `fioSwimPlay` | 五天后机库的“盐水账” |
| 安静漂一会儿 | `fioSwimQuiet` | 五天后工期表圈起准时下工的时间 |
| 菲尔线明确提出工作以外的两人邀约 | `fioSwimRomance` | 她主动牵手；五天后先交正式记录、再把下次时间写进信里 |
| 明确以朋友相处 | `fioSwimFriend` | 五天后压毛巾的石头用来压记录纸，询问艾达能否同行 |

新游泳邀约的 `promise.daysFromNow` 分别为2或4；静态 `day:42/44` 留作正常第40天入口的锚点。第84天最晚邀约可在第88天完成改约。

`fioSwimVisitDay` 保存实际赴约日。回响 `fio_swim_echo` 不早于第49天，且距实际赴约至少5天，防止旧存档延后赴约时立刻提前回忆。新字段保存在原有 `flags` 内；VERSION仍为1，旧对白缓存、行号和存档均保留。
