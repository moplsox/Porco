# 委托正文与接入说明

现有24项手工编写公告：18项首单，6项隔章后续单；30场可玩的委托场景。寻回、搜救、护送、邮运、测绘、追踪空贼六类各3首单。6首单有两个实质阶段，第一阶段通过 choices.next 进入第二阶段；之后再隔章展开后续单，合计三段故事。独立统计16293个去重正文字符（含中文标点），其中14671个CJK文字；不计选择文案、reply、公告理由、代码、UI等。

## 经济与时间约定

- jobs.json 的 reward 是公告最高报酬；实际所得只在最终 choices.effects.money 发放。第一阶段可能先付协作费，第二阶段结算，因此两阶段总收益要相加。
- 接单由引擎消耗 fuel、wear，按 duration 计时；场景 choices 中额外 fuel、condition 与 money 为事件途中增量。不要在结算时重复发 jobs.reward。
- 燃油与机况均为实际资源，不再在脚本重复扣购买费。净收入面板应以“实际收入−途中现金支出−消耗燃油的重置成本−损耗修复成本”展示，最终单价服从引擎账本。
- 前18项是各类首单。第19–24项有 followup:true 与 chain，并通过 requires.flag 等前单完成；没有把前章选项限定为唯一正确路径。部分完成也能开启后续共同生活。
- 所有报酬为里拉。额外请人协作既能保住约定也有实际成本；少收报酬可改善公共设施，但不凭支付金钱直接换女主好感。
- 需维持地图低门槛恢复机制，委托自身不会强制抢走重要邀约的时段；玩家在接单前应看到 duration。

## 叙事边界

没有以替别人原谅、牺牲隐私、免费替专业人员签字或多付礼物直接给亲密度的“正确选项”。合作烤炉、井址和医疗推车均在后续有能核对的生活变化；被追踪的人可劳动赔偿，但报案、索赔与工时不互相抵消。所有后续在flag门槛内真实可达，不存在未引用的尾声文本。
