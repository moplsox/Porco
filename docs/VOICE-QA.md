# 中文对白朗读验收

2026-11-26。实现为可选的浏览器/系统中文合成朗读，不是逐句录制的角色配音。默认关闭，使用设备可用的中文声音；无中文声音或没有 Speech API 时继续纯文字游玩。

## 实际接入

- 设置含对白开关、独立音量、语速、旁白开关，四组角色声音选择和试听。声音URI以字符串保存为设备偏好，不进入剧情存档。
- 逐句播放；长句分段，任一时刻只提交当前短段。新句、菜单、标题、隐藏页面、读档、导入、章节重选、静音或音量归零会取消旧声。
- 同句重渲染不重复发声；显式“重听本句”可单独读旁白，不改变自动朗读和旁白偏好。取消后的旧回调不能结束新句。
- 自动播放等待当前朗读结束；快进期间不排队。原生错误或缺失结束回调由错误处理及超时释放，避免阻塞游戏。
- 根目录单文件内嵌了语音控制代码，无新增录音文件、API密钥或应用服务器依赖。部分系统声音使用在线服务，离线声线是否可用取决于设备。

## 验证限制

语音单测与集成测试使用可控 SpeechSynthesis 模拟器，验证生产代码的请求、取消、设置与自动推进；不能证明真实声音的发音、情感、音色或设备可用性。

本轮托管浏览器预览在启动阶段失败：`sites-preview: relay could not open browser port 4173: timed out waiting for relay readiness`，随后status为stopped。没有启动替代服务器、修改权限或绕过基础设施。真实浏览器画面、手机触控及实际听觉验收本轮未验证；Mac/iPhone上的中文声音需在目标设备试听。此前file://管理员策略限制保留在STANDALONE-QA.md。
